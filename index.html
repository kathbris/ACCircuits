Formula reference
XL = 2πfL    XC = 1 / (2πfC)    L = XL / 2πf    C = 1 / (2πfXC)
Real coil: Zcoil = √(Rcoil² + XL²)    Rcoil = Z × PF    XL = √(Z² − Rcoil²)
Any load: Z = V / I   P = I²R = VR²/R   Q = I²X = VX²/X   S = V × I = √(P² + Q²)   PF = P / S   θ = cos⁻¹(PF)
SERIES: I is common   RT = ΣR   XT = |XL − XC|   ZT = √(RT² + XT²)
PARALLEL: V is common   Ibranch = V / Zbranch   IT = ST / ET   ZT = ET / IT
Totals: PT = ΣP   QT = |QL − QC|   ST = √(PT² + QT²) = ET × IT   PF = PT / ST
QL > QC → lagging    QC > QL → leading
